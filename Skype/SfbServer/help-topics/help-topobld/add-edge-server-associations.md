# Add Microsoft Edge Server Associations

[!INCLUDE[appliesto-2015-xxx-xxx.md](../../../SfBServer2019/includes/appliesto-2015-xxx-xxx.md)]

Use this page to select the Front End pools and Standard Edition servers that are to use this Edge pool for A/V traffic. 
  
Each front-end pool can be associated with only one Edge pool. If you select a front-end pool that is already associated with another Edge pool, it will change the association away from the previous Edge pool.
  
You can also choose to associate this Microsoft Edge Server or Edge pool with Mediation Servers or Mediation Server pools to configure and enable Enterprise Voice for external users.

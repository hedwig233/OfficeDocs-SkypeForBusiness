# Add Director Association for Lync Server 2010
 
[!INCLUDE [appliesto-2015-xxx-xxx](../../../SfBServer2019/includes/appliesto-2015-xxx-xxx.md)]

You define whether the Director or Director pool has a Monitoring Server associated with it. Select the check box to associate a Monitoring Server with the Director or Director pool.
  
> [!TIP]
> If you haven't yet created a Monitoring Server database (and optional instance), you'll be given the opportunity to create it later if you select this check box to associate a Monitoring Server with the Director or Director pool.
